Dự Án Thực Tế

Các mô hình hệ thống và bài tập lớn đã triển khai

System Admin

Hạ tầng Mạng Doanh nghiệp

Xây dựng Domain Controller trên VMware, cấu hình AD DS, chính sách nhóm GPO, đồng bộ thư mục DFS và kiểm soát tệp tin bằng FSRM.

DevOps

Web Server với Docker & Nginx

Đóng gói ứng dụng web và cơ sở dữ liệu MySQL vào container, cấu hình Nginx Reverse Proxy tối ưu hiệu năng và bảo mật.

ERP & Web

Vận hành Website & Odoo

Xây dựng trang web thương mại điện tử trên nền tảng Odoo, kết hợp thiết kế ấn phẩm đồ họa và quy trình vận hành trực tuyến.
